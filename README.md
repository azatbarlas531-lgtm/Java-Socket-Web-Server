

Java Socket HTTP Web Server

Bu proje, Java programlama dili ve TCP Soket altyapısı kullanılarak 3. parti hiçbir kütüphane kullanılmadan geliştirilmiş hafif bir HTTP Web Sunucusudur.

Özellikler
• Port: 1989
• Mimari: Multi-threaded (Çoklu İş Parçacıklı)
• SOLID Prensipleri: Tasarım modüler sınıflara ayrılmıştır.
• Teknolojiler: Java Soket Programlama, HTML5, CSS3

Projeyi Çalıştırma
1. Projeyi klonlayın veya indirin.
2. SimpleHttpServer.java dosyasını derleyip çalıştırın.
3. Web tarayıcınızdan http://localhost:1989 adresine gidin.
